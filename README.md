# GSB Bugfix Task
## 题面
报表中心改成按租户隔离存储后，甲租户的用户拿到了一份本属于乙租户的对账单，下载链接里的相对路径还能跳出根目录读到系统文件。旧实现把根目录和用户输入直接拼接，前缀比较没有分隔符边界，相邻目录名也能通过；百分号编码没有拒绝，编码后的点段照样生效；反斜线和盘符在部分平台上被当成分隔符；Unicode 组合形式不同，同一文件出现两个名字；下载句柄只放路径不绑租户，换个租户还能继续用，过期和重复使用也没人管。tenant_file_vault.py 里的 TenantFileVault 重做取件流程。创建时提供各租户根目录和文件索引。读取入口接收租户与相对键：租户不存在、键为空或超长都报错；键只能用斜杠分段，点段、上级段、空段、绝对路径、盘符、反斜杠、百分号编码、控制字符、末尾带点的段都拒绝；每个段长度与总深度有上限；键的 Unicode 形式必须已经是规范形式；系统的设备保留名不能当文件名；命中索引后给出大小、摘要和一次性句柄。句柄绑定租户并带存活时间，换租户兑换、过期兑换、重复兑换分别返回不同错误码。计数视图给出读取、签发、拒绝三项，是副本。索引键在建对象时按同一规则校验，重复键或越界键按配置错误处理；键比较区分大小写，也要拒绝只在小写化之后才重复的条目。句柄兑换成功立刻作废，未登记句柄单独报错。现有十五条断言眼下全部失败。
