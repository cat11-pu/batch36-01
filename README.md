# GSB Bugfix Task
## 题面
大促前共享缓存层连续命中脏数据，几家店铺的商品页被替换成竞争对手的图片。复盘发现边缘节点只把路径当键，查询串、站点名和内容协商信息都没有参与；攻击者在自己的店铺页面带一个冷门参数请求同一路径，就把带自家标识的响应写进公共条目，随后正常访客全部吃到这份内容。代理转发过来的站点名被无条件采信，伪造一下就能让整站条目挂到外部域名；携带登录凭据的请求也被当作公共资源缓存；重复参数、点段路径、百分号编码的分隔符各自拼出不同键，绕过清理。edge_cache_partition.py 的 EdgeCachePartition 要重做键的生成：构造参数给出受信站点集合与键长上限；只接受读请求，站点名去空白、转小写、去掉末尾点并只认可加密端口；非受信代理送来的转发站点名不得影响结果；查询参数按策略声明的集合收集，按名称排序，重名判为非法；路径里出现反斜杠、连续斜杠、点段或编码分隔符一律驳回；策略声明的协商头值进入键，缺失时用空串占位；带凭据的请求标记为私有并返回不可共享；键过长单独报错；统计接口返回加锁计数和隔离副本，能分开看到公共条目、私有请求与非法输入的数量。同一路径在压缩与非压缩版本之间不能共用条目；查询值为空串要保留占位，不能和缺少该参数混同；站点名带显式默认端口时归一到无端口形式；键里只出现规范化后的字段，不保留原始请求行；条目写入后如果响应声明按会话变化，要立刻降级为私有并让旧副本失效。现有十五个测试全部失败，测试文件不得修改。

```bash
python -m pytest tests -q
```
