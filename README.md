# GSB Bugfix Task
## 题面
计费服务从内网直连改成统一网关后，出现了几笔不该有的扣费：调用方伪造了转发链里的对端信息，网关看到转发头就当真；方法名没有按调用方限制，调试接口被人调通；元数据键名大小写混用，重复键取了最后一个；令牌没有校验签名和有效期，同一个随机串还能反复使用；租户字段可以随便填；超时声明写成很大的值，慢调用把连接池占满。billing_metadata_gate.py 中的 BillingMetadataGate 按调用方逐项核对。初始化时登记每个调用方的身份标识、签名密钥、允许的方法和租户，并给出时钟偏移与元数据体积上限。入口拿到调用信息：方法名、调用方、对端信息、有序的元数据键值对。调用方未登记、方法不在集合内分别报错；对端必须走加密连接且身份与登记值一致，转发头一律忽略；元数据键只允许小写字母数字和连字符下划线点，大写键、二进制后缀键、重复键、未知键分别处理；总字节数超过上限拒绝；授权恰好一份，令牌由调用方、到期时刻和随机串组成并以签名封尾，签名不符、到期、随机串重复分别报错；请求标识符合固定长度十六进制；租户在允许集合内；超时是毫秒数且不超过上限。成功时给出调用方、方法、租户、请求标识和超时毫秒数；计数视图给出通过与拒绝两项，是副本。令牌签名比对须恒定时间，随机串在时间窗口内只出现一次。时钟偏移两侧都留余量，到期时刻过远也拒绝。这组用例共十五条，目前全部失败。

## 运行方式
```bash
python -m pytest tests -q
```
