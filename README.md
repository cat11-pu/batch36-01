# GSB Bugfix Task
## 题面
跨端通行密钥启用云同步后，客服发现同一枚密钥条目在手机与笔记本上各记一份。备份资格为假的条目被写进同步封包，恢复时导出一枚根本无法同步的密钥；备份状态为真、备份资格为假的组合同样落库；终端资质声明过期三天仍可提交封包；同一密钥条目的版本序号发生回退，服务端照单全收，旧封包覆盖新封包；已被吊销的平板还能继续推送；同一终端上报的签名计数下降，代码毫无察觉仍照常更新；封包中的站点标识与本服务不同也能合并；验签钩子返回假，流程依旧报成功；一枚密钥条目挂到五台终端，持有终端清单没有上限；终端编号重复入册时旧记录被悄悄替换；封包里的密钥编号为空串也能通过；同一终端连续提交两个版本序号，两份都落库；账本快照被调用方改坏后污染内部数据；吊销某台终端后，它独有的密钥条目仍能解析出来；终端资质声明缺少公钥指纹也放行。passkey_sync_ledger.py 的 PasskeySyncLedger 负责终端入册、同步封包合并与密钥解析：终端编号非空且不可重复，资质声明必须在有效期内并带公钥指纹；封包只能来自已入册且未吊销的终端，验签钩子必须为真；站点标识逐字相等；密钥条目必须同时声明可备份与已备份；同一密钥条目的版本序号只能严格递增，重复序号只生效一次；同一终端的签名计数只能递增，跨终端解析取最大值，倒退视为克隆并拒绝；持有终端数量超过上限要拒绝；吊销终端后剔除它独有的条目，已吊销终端再提交按吊销处理；解析未知条目和导出快照都要给出明确错误或深拷贝。仓库自带的十五条断言眼下全红，测试文件不可改。

## 运行方式
```bash
python -m pytest tests -q
```
