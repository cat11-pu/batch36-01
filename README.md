# GSB Bugfix Task
## 题面
双因素认证上线备份码后，支持工单里出现两类问题：用户说码用不了，安全团队说码被重复使用。生成的备份码是十位纯数字，撞库脚本几分钟就能试完；同一批里出现重复码；库里存的是明文，导出报表时整批泄露；用户输入小写并带空格时被判定无效；已经消费过的码再提交一次，剩余次数又减一；输错五次也不锁定，暴力尝试畅通无阻；重新生成后旧码仍然有效；一批码用完之后接口还返回成功；备份码没有有效期，三年前的批次还能用；空字符串被当成合法输入；生成数量传负数时返回空列表而不是报错；并发提交同一个码，两个请求都返回成功；失败计数在成功消费后没有清零，用户被莫名锁定；锁定窗口过了也不会自动解锁；导出快照里能看到盐值并被外部改写。backup_code_vault.py 的 BackupCodeVault 要实现生成、消费与吊销：码用去掉易混淆字符的大写字母表生成，形如四段四位、以连字符分隔，一批内不得重复，数量限定在一到二十之间，否则抛 ValueError；只保存带随机盐的哈希，导出状态里不能出现明文和盐；消费前先做归一化，忽略大小写、空格和连字符；每个码只能成功消费一次，重复提交按已使用拒绝且不改变剩余数量；连续失败达到阈值后锁定该用户，锁定期内正确码也不能用，锁定窗口过后自动解锁，成功消费后失败计数归零；每批码有有效期，过期整批作废；重新生成要让上一批立即失效并返回新的明文列表；未知用户、空码和已耗尽的批次分别拒绝；并发消费同一个码只能有一个成功。15 条断言现在全红，测试文件保持原样。

## 运行方式
```bash
python -m pytest tests -q
```
