# GSB Bugfix Task
## 题面
前端把静态资源整体切到公共分发网络后，安全扫描发现页面引用的脚本被替换过，而标签上的完整性标记仍然通过。旧逻辑只检查字符串里有没有摘要前缀，空值和弱算法也算合格；同一标签写多枚摘要时，任意一个弱算法命中就放行；摘要长度不做校验，截断的编码也能过；编码字符集没有限制，换行和空格被静默去掉；算法名大小写混写；标记缺失时按无需校验处理；跨源属性缺失也继续加载；明文源直接放行；内容以字符串传入时被当成字节；同一资源多次校验的计数互相覆盖。asset_digest_sentinel.py 的 AssetDigestSentinel 要在渲染标签前把关：校验入口接收标签、实际内容和当前时刻；完整性标记必须存在且非空，按空白拆成多枚令牌，每枚形如算法加连字符加摘要；算法只认 SHA-2 家族中三种强度，名称统一大小写后比较，未知算法忽略但不得单独构成通过；摘要必须是标准编码且解码后长度与算法匹配，非法字符、缺失填充和折行都驳回；同一标签出现多枚同强度摘要时任意一枚匹配即通过，存在更强算法时弱算法不得单独放行；实际内容必须是字节串；跨源属性只接受两种取值；源地址限定为加密传输或站内根相对路径，明文、协议相对和空地址拒绝；结果返回命中的算法与摘要位置；统计接口记录通过、失败和摘要不符次数，且给出独立副本。允许算法集合按强度排序，重复算法只保留一项；令牌之间允许任意空白但不得出现空令牌；摘要比较按解码后的字节做常量时间比较，不得提前返回；同一标签里两个不同算法都匹配时取更强那个；标记值出现逗号、分号、引号或反斜杠按格式错误处理；源为站点名时不得夹带登录凭据，端口只允许加密默认端口；站内相对路径不得以连续两个斜杠起头；统计接口区分通过、格式失败、摘要不符与策略失败。仓库自带十五条用例眼下均未通过。

## 运行方式
```bash
python -m pytest tests -q
```
