# GSB Bugfix Task
## 题面
会话改造后，多个子域应用开始互相读到对方的登录态：带主机前缀的票据被配上父域，浏览器拒收，用户反复掉线；带安全前缀的票据没加安全标记也照样下发；同站策略设为无限制却缺安全标记，被现代客户端直接丢弃；路径写成子目录却使用主机前缀；分区属性与宽松同站策略组合被接受；存活秒数写成负数或数字字符串；自定义属性名拼错后静默忽略；同一次响应里同名票据出现两次，后一个覆盖前一个；值里夹分号和折行也能拼进响应头。session_cookie_issuer.py 的 SessionCookieIssuer 要集中签发会话票据：签发入口接收名字、值和属性表，名字必须是合法 token，值不得含分号、逗号、空白、引号和控制码；属性名大小写不敏感且不得重复，未知属性驳回；带主机前缀时必须同时满足安全标记、根路径、无域、未分区；带安全前缀时必须具备安全标记；同站策略只认三种取值，无限制必须配安全标记；分区属性必须同时具备安全标记与无限制同站策略；域去掉前导点后必须等于配置站点域，否则拒绝；存活秒数必须是非负整数；渲染顺序稳定，不输出空属性；解析入口接收多条响应头，按名字去重，重复或非法头报错；统计接口记录签发、解析与失败次数，并发下不丢计数，且返回隔离副本。属性值里的制表符与不可见字符要驳回；到期时间与存活秒数同时出现时以存活秒数为准，但两者都要校验；域为空串不能当成未设置；路径缺省时补根路径并在结果里标记；同名属性字母大小写不同也算重复；解析遇到空头、缺少等号、只有属性没有值都要报错；一次响应里的票据数量设上限；统计接口区分签发、解析与失败三类。仓库附带的十五条测试现在全部报错。

## 运行方式
```bash
python -m pytest tests -q
```
