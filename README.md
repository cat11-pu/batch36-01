# GSB Bugfix Task
## 题面
客服系统开放自定义通知模板后，退信和投诉同时上涨：有人在称呼里塞入换行，邮件凭空多出隐藏抄送；主题里夹带编码后的折行，被网关拆成新字段；收件地址末尾跟一个尖括号，实际投递跳到外部域；自定义字段名混入冒号，一行被解释成两个头。更隐蔽的是密送地址仍出现在最终文本里，重复收件人没有合并，域名里带下划线也放行。smtp_header_composer.py 的 SmtpHeaderComposer 要把业务消息组装成可投递邮件：输入包含发件人、收件人、抄送、密送、主题、附加字段和正文；所有字段值先检查回车、换行、空字节以及除水平制表符之外的控制码，显示名不得含尖括号、引号、逗号、分号和反斜杠；地址只允许一个 @，本地部分和域名都不能为空，域名标签要符合规则，带空白或折行的地址按注入处理；主题去掉首尾空白后不能为空并限制长度；收件总数受配额约束，跨三个收件列表的重复地址按小写比较；附加字段名只接受 token 字符，不得覆盖系统保留字段；正文禁止空字节并限制长度；最终文本不得出现密送行，但信封收件人必须包含密送地址；统计接口返回成功与失败计数，且是隔离副本。显示名中的中文标点原样保留，但制表符、零宽字符与双向控制符要单独判定；域名不能以连字符开头或结尾，也不能出现连续圆点；本地部分区分字母大小写，域名比较不区分；附加字段总数设上限，重名要报错而不是后者覆盖前者；正文出现单独回车也要驳回；渲染时每个字段一行，行尾统一回车换行，末尾补一个空行；失败计数要覆盖地址、字段名、字段值和正文四种来源。现有十五个断言眼下全部报错。

## 运行方式
```bash
python -m pytest tests -q
```
