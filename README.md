# GSB Bugfix Task
## 题面
边界流量的检测脚本在压测时漏报明显：规则表里有几十条特征串，代码却对每条规则各跑一遍子串查找，大小写、词边界和重叠位置都按最省事的办法处理，结果 concatenate 里的 cat 也被算成一次命中；同一段正文里两条特征相互重叠时只保留先命中的那条；一条规则在一行里重复出现十次也只记一次；空串规则把整段内容判成恶意；重复的规则编号在加载时没人拦；超出长度上限的请求体照样进匹配，调用方传字节串时程序直接崩掉；规则热更新后旧命中缓存没有清掉，上一版的特征串还在报；命中里的匹配片段按解码后正文截取，和原始报文对不上；空规则表被当成配置错误，服务起不来。ids_signature_multimatch.py 里的 SignatureMultimatch 要改成一趟多模式扫描：构造参数接收规则列表、命中上限与正文上限，每条规则包含编号、特征串、严重级别与标志，标志可省略；编号不可重复，特征串不能为空且不得含控制字符，严重级别只认 info、low、medium、high、critical 五档，标志只认 nocase 和 word，其他取值在构造时就报错；规则表必须是列表，可以为空；编号只允许小写字母、数字与连字符，长度不超过三十二；同一标志重复出现只算一次。默认区分大小写，带 nocase 时忽略字母大小写；带 word 时特征串前后必须是边界，不能紧邻字母、数字或下划线。允许重叠，同一规则在同一位置的多次出现要分别给出偏移与长度；命中先按偏移再按规则编号排序，超过条数上限截断并标记；请求体必须是字符串且不超过正文上限；扫描成功与失败分开计数，统计接口返回扫描次数、命中总数与失败次数，并发下计数不丢且给出独立副本。

## 运行方式
```bash
python -m pytest tests -q
```
