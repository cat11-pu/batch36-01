# GSB Bugfix Task
## 题面
登录页改版后，钓鱼邮件开始批量借用站内继续跳转地址：链接看着是公司域名，点开却落到外部站点。攻击者试出的路子包括双斜杠开头的网络路径、反斜杠被浏览器当成斜杠、地址中夹带登录凭据伪装站点、明文协议与脚本协议、受信域名后接圆点或加端口、子域后缀仿冒、路径里编码过的分隔符和嵌套编码、回车换行改写响应头，以及连续多级嵌套把用户送到第三跳。continue_route_tribunal.py 的 ContinueRouteTribunal 负责解析登录后的继续地址：构造参数给出精确受信站点集合、默认落点和最大跳数；输入为空时直接返回默认落点；含回车、换行、空字节或制表符的判非法；相对地址必须以单个斜杠开头，反斜杠或双斜杠开头视为网络路径；绝对地址仅接受安全传输形式，禁止登录凭据、片段和非标准端口，站点名去末尾点、转小写后与集合逐字比较，不做后缀推导；百分号编码最多展开三层，任何一层出现分隔符、反斜杠、空字节或折行一律判非法；点段先归一，越过根目录报错；查询串里再次嵌套目标时按跳数复核，越界拒绝；记录接口分别统计成功、回退与失败，并保留最近错误码，并发下不丢计数，返回隔离副本。受信集合本身也要先规范化，重复项按配置错误处理；相对地址里的查询串原样保留但不得重复解码；绝对地址路径为空时补根路径；末尾圆点、字母大小写与国际域名按同一规则处理；跳转值里出现用户名密码分隔符、at 符号或连续问号都要驳回；默认落点必须是站内根路径；记录接口分别保存成功、回退和失败，最近一次错误码可以单独取出。仓库里的十五条断言当前均未通过。

```bash
python -m pytest tests -q
```
