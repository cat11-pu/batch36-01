# GSB Bugfix Task
## 题面
工单系统支持粘贴链接后自动抓取站点预览图，安全同学用一个外部域名就把请求引到了云上的实例元数据地址。旧实现只对字符串做黑名单，域名解析出来的地址从不检查；跳转只跟一跳，第二跳换成内网地址照样放行；跳转地址写成相对形式时被当成新站点；解析结果在检查之后又变了一次，实际连接用的是另一台机器；非加密协议、带账号密码的地址、非常规端口都没有拦；跳转成环时一直重试。link_preview_warden.py 中的 LinkPreviewWarden 按跳转链逐跳裁决。创建时传入解析器、抓取器、允许端口、最大跳数和响应大小上限。入口接收原始地址：只接受加密协议；地址里出现账号密码、片段、非法端口或裸地址字面量都拒绝；站点名只允许字母数字和连字符组成的标签；每一跳先解析，结果里只要出现回环、私网、链路本地、组播或保留地址就整条拒绝；同一站点第二次解析结果与首次不同按解析漂移处理；跳转状态必须带目标地址，相对目标按当前地址补全；跳转次数超限、回到已经访问过的地址分别报错；最终响应超过大小上限也拒绝。成功时给出最终地址、跳数、实际使用的地址和内容摘要；计数视图记录放行、拦截与最近错误码，并发下计数不丢且返回副本。跳转状态只认重定向那几种，其他非成功状态单独报错。随附十五条用例目前全红。

## 运行方式
```bash
python -m pytest tests -q
```
