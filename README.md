# GSB Bugfix Task
## 题面
门户接第二家身份提供方后，登录态校验开始漏风。算法标成 none 的令牌能过；头里的 kid 在 JWKS 里查不到，代码干脆不验签；签名钩子返回假，流程只写一行日志继续放行；iss 多一个斜杠、少一个斜杠都被当成同一家；aud 是数组时只看第 0 个元素，旁的应用令牌混了进来；多受众时 azp 缺失或者写着第三方，也照样建立会话；令牌到期两小时仍被接受，签发时刻落在未来也没人拦；会话发起时落下的随机值没有回查，同一个值第二次提交还能再登一次；sub 是空串或纯空格直接入库；时钟偏移窗口写死成十分钟，构造参数里的值从未生效；密钥集合为空时整段验签被跳过；alg 名写成小写也被放行。idtoken_claims_gate.py 的 IdTokenGate 按 OIDC 规范验收身份令牌：算法限清单内的非对称项，kid 必须在公布集合中且验签通过；iss 逐字相同；aud 允许字符串或字符串列表并须包含本客户端，多受众时 azp 等于本客户端；exp 与 iat 对照当前时刻并采用可配置偏移；随机值与会话一致且一次性；sub 去空白后非空；令牌头缺 alg 或 kid 直接拒绝，错误要带可区分原因的错误码；错误码要稳定，资源方据此决定是重试还是要求重新登录；日志里只记错误码和 kid，不打印令牌体；header 不是字典、受众是空数组、exp 或 iat 不是整数，都按非法令牌处理；验签钩子抛异常要转成签名错误码，不能让异常冒到网关；随机值在失败校验后不占用，成功后才标记消费；受众里出现空串或纯空白也算不合法；同一个随机值只绑一个会话。十五条断言眼下全红，不许改测试。

## 运行方式

```bash
python -m pytest tests -q
```
