# GSB Bugfix Task
## 题面
视频工坊把转码参数开放给运营配置后，有人的输入带了额外的命令行选项，输出文件被写到工作目录外，还有请求把系统命令拼进参数。旧实现把命令名和参数用空格拼成一整条字符串交给系统 shell，分号和管道直接生效；输入输出路径来自表单，跨越上级目录和绝对路径都放行；预设和滤镜没有白名单，以连字符开头的值被当成新选项；码率接受布尔值和越界整数；作业对象里多出来的字段被原样透传；执行时继承父进程全部环境变量。transcode_job_planner.py 中的 TranscodeJobPlanner 改成参数数组加固定模板。调用方创建时指定工作目录、允许的滤镜集合、允许的预设。规划入口接收作业对象，未知字段直接拒绝；输入键与输出键限定为相对路径，越过上级目录、以斜杠起头、带驱动器前缀、含反斜线、含零字节、后缀不符都拒绝；滤镜名须在集合内，参数只能是名字加数字，任何连字符打头的值都拒绝；预设须在允许集合内，码率是零到五十一之间的真整数；显示名仅用于展示，不能以连字符开头或含控制字符；规划结果给出完整参数数组和输出绝对路径，数组按输入、滤镜、预设、码率、输出五段的固定顺序拼装，用户给的值不得成为独立选项。执行入口只认本对象生成且未被篡改的规划，用注入的执行器运行，环境变量只留固定两项，超时与工作目录固定；计数视图给出规划、执行、拒绝三项和副本。执行器异常转成专用错误码，标准输出只保留末尾一段。随附用例十五条，当前均不通过。

## 运行方式
```bash
python -m pytest tests -q
```
