# GSB Bugfix Task
## 题面
多租户入口迁移后出现串站：访问甲商户域名的用户拿到乙商户的登录表单，证书告警也集中爆发。旧逻辑只把主机头做子串判断，大写形式、末尾圆点、显式端口都能落进不同分支；请求行里写了绝对地址时，代码相信了地址中的 authority 而不管主机头；两个同名头同时出现时取了靠前那个；代理追加的转发主机名被直接当真；带用户信息、逗号拼接、空标签、超长标签的值没有语法检查；安全层协商名与主机头不一致也照常放行；未登记域名悄悄落到默认站点，把内部后台暴露出来。vhost_route_guard.py 的 VirtualHostRouter 需要按站点登记表严格解析：请求可为普通来源形式或绝对形式，主机头必须有且只有一份，比较前统一小写并去掉末尾圆点；绝对形式里的 authority 要与主机头逐字一致；含用户信息、逗号、空白、控制码、非法标签或非标准端口的输入一律驳回；只有受信代理地址送来的转发主机名才参与判断，且与主机头冲突时单独报错；存在安全层协商名时必须与规范化后的主机头相同；登记表未命中返回专用错误码，禁止静默回退；结果给出站点标识与规范化站点名，统计接口返回成功、失败计数及隔离副本。站点登记表里的别名只做完整匹配，不接受前缀或后缀推导；主机值出现百分号编码、末尾冒号、空标签或超过六十三字符的标签要驳回；网际协议字面量只在登记表显式存在时接受；连接类方法不得走普通虚拟主机路由；同一连接改换主机名必须重新解析；默认站点只有在配置明确允许时兜底，并要单独标记；失败原因需要区分语法错误、未登记站点与代理头冲突。仓库附带的十五个用例当前全红。

