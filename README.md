# GSB Bugfix Task
## 题面
会员中心接进外部数据看板后，一次红队演练只用匿名页面就取走了携带登录态的明细。旧配置一边允许请求带登录凭据，一边又把通配符写进受信站点集合；浏览器送来的来源地址被照抄回去，字母大小写和末尾斜杠都不设防；来源为空字面量时直接放行；子域通配把整个父域都信任了；预检阶段把页面点名的字段全部回显，方法也没有许可集合；预检结论缓存一整天，权限收回后浏览器仍用旧结论；失败分支同样带跨域许可；响应缺少随来源区分的缓存分桶标签，缓存把甲站的结论发给乙站；内网访问标记没有单独限制。cors_preflight_arbiter.py 的 CorsPreflightArbiter 要统一裁决：初始化时给出的受信来源逐条精确匹配，需要凭据模式禁止通配符配置，否则构造即报参数错误；判断时区分预检与真实请求，来源缺失、为空字面量、带路径、带逗号或空白都驳回；协议、站点名、端口必须与集合完全一致，不做子域推导；预检方法与请求字段必须在许可集合内，重复字段去重后校验；返回的缓存秒数不得超过配置上限；需要凭据时回显具体来源并附凭据标记，不需要凭据时才可使用通配符；预检结论必须带随来源区分的缓存分桶标签，真实响应不得出现预检专属字段；内网访问请求单独判定；失败分支不得输出任何跨域许可；计数视图汇总裁决数量，结果为独立副本。比较来源前去掉首尾空白并拒绝不可见字符；受信集合出现重复项、通配子域或带路径条目时构造失败；预检请求缺少请求方法字段按非法处理；请求字段名统一小写后比较，空名与重复名去重；真实请求不得夹带预检专属字段；缓存秒数为零也要输出且不能为负；响应字段顺序稳定，凭据标记只允许小写 true；计数视图另按预检、真实与异常分组。仓库自带的十五个用例目前全红。

## 运行方式
```bash
python -m pytest tests -q
```
