# GSB Bugfix Task
## 题面
客服坐席工作台改用长连接后，安全团队发现外部页面能借坐席浏览器连上内部通道：握手只看会话票据是否存在，来源头根本没校验；票据放在地址查询串里，代理日志全都记了下来；同一个来源头出现两次时取了第一个；版本号和升级标记没有检查；子协议由客户端随便挑；票据用过一次还能再用，换一个租户也能用。agent_console_handshake.py 中的 AgentConsoleHandshake 把入口管住。初始化时登记每个租户允许的来源、允许的子协议和票据清单。握手入口接收租户与请求，请求带大小写不敏感的头表和客户端子协议列表。来源头恰好一份，字面量空值、通配、带路径、带查询串、带账号密码、非加密协议或非默认端口都拒绝；来源的站点与端口得和主机头对上，规范化时转小写、去掉收尾的点；升级标记必须同时含两个约定令牌，版本必须是十三；连接键必须是解码后十六字节的标准编码；子协议至少命中一个租户允许值，多个命中时按客户端顺序取第一个并在结果里回显；票据从专用头读取，不认查询串，票据须属于该租户、未过期、未使用，兑换成功即作废；路径须是约定值；缺失的必填头单独报错。只读计数给出放行与拒绝两项，是副本。票据口令比较要恒定时间，同一票据在并发下只能成功一次。这批题共十五条测试，当前全部失败。

## 运行方式
```bash
python -m pytest tests -q
```
