# GSB Bugfix Task
## 题面
代码仓库做密钥扫描，第一版把所有长度超过二十的字符串都报出来，锁文件和压缩后的前端产物制造了上千条噪声；安全同学把阈值调高后，真正的访问密钥又漏了；同一行里两个令牌只报第一个；注释里的示例值和占位符被当成真密钥；二进制文件读进来全是空字节，扫描器直接卡死；报告把命中的原文完整写进工单，反而造成二次泄露；路径里带上级目录时仍然继续扫；候选切分把网址片段和哈希值也当成令牌；同一密钥在相邻两行重复出现时报告刷屏；预览长度固定后仍能反推出原文长度；大文件被整段读入内存，扫描还没开始就超时。credential_entropy_triage.py 的 CredentialEntropyTriage 负责分诊：构造参数给出最短与最长候选长度、熵阈值、放行路径前缀、占位符标记与已知服务前缀；扫描入口接收文本与相对路径，路径出现上级目录、盘符或反斜杠开头的形式要拒绝；放行路径前缀命中的文件直接跳过并标记；文本含空字节按二进制输入拒绝；候选按连续字母数字与加号斜杠等号下划线切分，长度不在区间内的直接忽略，超长候选不截断而是整段丢弃；对候选计算字符熵，达到阈值且长度合格才记为高熵命中；包含占位符标记、全部字符相同或明显递增序列的候选不报；带已知服务前缀的令牌即使熵不足也要单独标记；同一行多个命中按列号排序；预览只保留前四位与后两位，中间以省略号代替；行号与列号都从一开始；候选判定基于原始文本，不做大小写折叠；统计接口记录已扫描文件数、命中数与抑制数，跳过与拒绝分别记录，并发下不丢计数且返回副本。

## 运行方式
```bash
python -m pytest tests -q
```
