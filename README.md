# GSB Bugfix Task
## 题面
素材库改版后，设计团队可以整包导入素材，运维发现导入目录里冒出本不该有的配置文件，磁盘也被写满。旧流程按成员名直接拼落盘路径：含上级目录、以斜杠带头、Windows 驱动器前缀、反斜线的成员照写；软链接成员先落地，后续成员再往链接目标写；同名成员只在大小写完全一致时判重，在大小写不敏感的文件系统上互相覆盖；目录成员与文件成员占住同一路径时不查冲突；条目数和展开总量没有上限，压缩比再离谱也照收。material_bundle_stager.py 中的 MaterialBundleStager 把导入拆成两步。第一步拿到成员清单和目标根目录，成员含名称、类型、压缩后大小、展开后大小；名称只能是靠正斜杠分段的相对路径，上级段、当前段、连续斜杠、以斜杠带头、驱动器前缀、反斜线、零字节、控制字符都拒绝；软硬链接成员直接拒绝；目录成员以斜杠结尾，普通成员不能以斜杠结尾；每段不得以点或空格收尾，也不能撞上系统预留的设备名；大小写归一后重复的路径、文件与目录互相占位的路径都算冲突；条目数、单件体积、总体积、压缩比四项上限在对象初始化时给定；第一步的结果按路径排序并给出总体积，同一清单重复计算结果一致。第二步只认本对象产出、未被改动的结果，回报写入清单；运行统计里有规划数、执行数、拒绝数，取出来的是副本。压缩后大小为零的普通成员按非法处理，目录成员不计入总量。测试文件十五条，当前全部失败。

```bash
python -m pytest tests -q
```
