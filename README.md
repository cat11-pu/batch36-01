# GSB Bugfix Task
## 题面
基础设施仓库接入计划门禁后，漏网越来越多：对象存储桶的访问控制写成公共读照样合入；安全组规则里全网段放行二十二端口没人拦；云策略里动作写成星号也能过；计划阶段值还是未知的字段被当成安全直接跳过；豁免单没有截止时间，永久生效；同一个资源换到别的地址后旧豁免还能复用。请重写模块 iac_plan_sentinel 中的 PlanSentinel：构造时传入规则、豁免单和当前时间。每条规则有编号、资源类型、字段路径、比较方式、目标值和严重级别，资源类型允许星号通配，字段路径用点号访问嵌套字段，比较方式支持相等、不等、属于、不属于、包含、不包含、存在和缺失；规则编号重复、比较方式未知、豁免单缺事故单号或截止时间都要在构造阶段报错并带错误码。扫描读取计划里的资源变更，跳过动作只有删除的资源，按变更后的对象判断；如果目标字段出现在未知字段集合里，必须按未知值违规处理，不能放行；缺失字段时只有缺失规则命中，其余规则不命中。豁免单必须同时匹配规则编号和完整资源地址，事故单号非空且当前时间早于截止时间才生效，过期豁免不算；被豁免的项按规则编号和地址两个字段放进豁免列表，未豁免的放进违规列表，两边都按地址和规则编号排序。计划结构不合法、资源变更不是列表、变更后对象不是字典都要报错。仓库里十五条测试现在全红，测试文件不要改；八个线程同时扫描同一份计划，结果不能有差异。资源地址必须是类型加名字的形式，缺失或重复地址要报错；同一资源多条违规先按严重级别从高到低再按规则编号排；字段路径为空表示检查整个对象，此时只允许存在和缺失两种比较；包含和不包含既能用于列表也能用于字符串，属于和不属于要求目标值是列表，类型不匹配按规则非法；豁免截止时间必须大于零，事故单号去空白后不能为空。

```bash
python -m pytest tests -q
```
