# GSB Bugfix Task
## 题面
内容安全策略上线后，报表页图表全部白屏，攻击者注入的内联脚本却能执行。值班同学发现随机串由时间戳取模生成，连续刷新能猜出下一枚；同一枚随机串在多个响应里复用；部分路由把它写死成常量；长度只有八位，字符集还混进加号和等号；策略同时保留内联放行指令，浏览器看到随机串就忽略内联限制；动态脚本指令在没有脚本随机串的页面上也被开启；多个中间层各拼一份脚本来源，重复项越堆越多；违规上报接口把整段会话票据和认证信息原样收进日志；超长拦截地址没有截断；上报体越过配额仍写入。csp_nonce_planner.py 的 CspNoncePlanner 负责生成策略：构造参数注入随机源、随机串最小与最大长度、复用窗口；每次规划取一枚新串，只接受 URL 安全的字母数字字符集且长度达标，窗口内重复报错，窗口外才可复用；把随机串加入配置指定的指令，默认脚本来源；该指令里原有的内联放行值必须移除并在结果中标记；动态脚本指令所在位置若没有随机串支撑则拒绝；指令名只允许小写字母和连字符，值不得为空，重复值去重且顺序稳定；只读开关决定输出哪一种策略头；上报入口只保留白名单字段，拦截地址截断到二百字符，出现会话票据、认证信息、写入票据等敏感键直接驳回，序列化后越过四千字节报错；计数视图汇总规划与异常数量，结果为独立副本。同一份策略里随机串只能出现在指定指令，其他指令不得被顺带改写；指令按策略给定顺序输出，随机串放在该指令首位；随机串不得进入上报内容或日志；上报里的来源文件只保留站点与路径，查询串丢弃；采样率与上报地址单独校验，地址只允许站内相对路径；重复初始化同一策略要能发现配置漂移；计数视图另按规划、异常与上报分组。现有十五条用例全部失败。

```bash
python -m pytest tests -q
```
