# GSB Bugfix Task
## 题面
阅卷系统开放附件提交后，审核发现一批自称图片的答卷其实带脚本：校验只认后缀，客户端报的类型被直接采信，换个名字就混进队列；同一个文件既能被图片查看器打开，又能被解释器执行；压缩包改后缀当图片交上来，解包后才露馅；文件名里带路径，落盘位置跑出了上传目录。answer_sheet_intake.py 里的 AnswerSheetIntake 要在入库前完成识别。初始化时提供允许的类别表，每类含声明类型、后缀和开头字节，另给单件大小上限。入口接收文件名、声明类型和内容：内容不是字节串、空内容、超过上限各自报错；用开头字节做最长匹配确定真实类别，匹配不到就拒绝；声明类型或后缀与真实类别对不上都要单独报错；文件名出现斜杠、反斜线、零字节、控制字符一律拒绝，双后缀只看最后一段；内容其他位置又冒出另一类别的开头字节，按夹带处理并留在隔离区；同样内容按摘要去重，重复提交只登记一次并沿用首次的存储名；存储名只由摘要决定，不掺用户信息。计数视图给出接收、拒绝、重复三项，返回的是副本。后缀比较忽略大小写，正式存储名统一小写；文件名过长或只有后缀也不收；并发提交同一内容只产生一个存储名。随附测试共十五条，眼下逐条失败。

## 运行方式
```bash
python -m pytest tests -q
```
