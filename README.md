# GSB Bugfix Task
## 题面
邮箱免密登录上线一周，安全团队复现了整条攻击链。链接里的票据是自增序号，换个数字就能登别人的号；票据核销之后仍然可用，邮件被转发后第二个人也能进；链接十五分钟不失效，三天前的邮件还能点开；同一地址连续点两次发送，两封信里的链接都活着；地址大小写和首尾空格被当成两个账号；回调地址只校验前缀，攻击者拼一个形似域名就能把票据带走；票据原文写进数据库，导出报表时整批泄露；绑定浏览器的随机串没有校验，复制链接到另一台设备照样登录；输错绑定串五次也不上锁；票据为空串时被当成合法请求；注销某个地址时只清了最近一条记录。magic_link_dispenser.py 的 MagicLinkDispenser 负责签发与核销：地址先去空白转小写，同一地址再次签发要让旧链接即时失效；票据高熵、落库只留摘要、绑定一次性浏览器随机串，有效期内只认一次核销；回调地址必须在白名单内且逐字相等；绑定串不匹配计入尝试次数，超过上限封锁该地址；作废或替换掉的链接一律按已核销处理，不能悄悄复活；未知、过期、已核销、绑定不符分别报不同错误码；签发时绑定串和地址都不得为空，回调地址里的片段和查询参数要原样保留但不能参与白名单比较；同一浏览器重复点击只应留下一条可用链接；封禁期间重新签发也要拒绝，避免用新链接绕过上限；摘要使用不可逆算法，不能从摘要还原链接；快照不得出现票据原文且为副本。仓库自带的十五条用例现在全红。

## 运行方式
```bash
python -m pytest tests -q
```
