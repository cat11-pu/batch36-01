# GSB Bugfix Task
## 题面
生产库的紧急提权上个月被滥用：值班同学自己发起、自己批准，五分钟就拿到管理员；事故单已经关闭，租约还在生效；有人续租了四次，累计在线一下午；审批人重复点批准也能凑够两人；申请理由只写了一个字照样通过；同一个人连开两张单，审计里出现两条活跃租约。请重写 breakglass_lease.py 里的 BreakglassLease：构造时传入单次时长上限和续租次数上限。申请接收用户、事故单号、分钟数、理由和当前时间，单号必须以固定前缀开头，理由至少十个字符，分钟数在一到上限之间，同一个人已有待批或生效租约时报冲突，返回租约编号；批准记录审批人，申请人不能批自己，同一审批人不能重复批准，第二个不同审批人批准时租约立即生效，生效时间取第二次批准的时间；状态查询在租约生效且未过期时返回包含用户、单号、到期时间、剩余分钟的字典，否则返回假，动作只允许读取和管理，授权角色、修改策略、修改审计全部拒绝；续租需要另一名非申请人的审批人，单次延长不超过上限，总续租次数不能超过上限；关闭事故单后该单所有租约立即失效；撤销可以提前终止。错误统一用带错误码的异常，错误码覆盖单号非法、理由过短、时长非法、已有待处理、不能自批、重复审批、续租超限和租约未生效。仓库十五条用例现在全红，测试文件保持不变；并发给同一个人开单时只能有一个拿到编号。租约编号每次申请唯一，审批记录按时间顺序保留；剩余分钟向下取整；关闭事故单只影响该单下的租约；待批租约超过有效期仍未凑齐审批时按自动关闭处理，后续批准报租约未生效；审计记录要能区分申请、批准、生效、续租、关闭和撤销。

## 运行方式
```bash
python -m pytest tests -q
```
